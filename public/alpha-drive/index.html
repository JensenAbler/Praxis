Alpha Drive Tools

Personal Google Drive utilities operated by Jensen Abler. This project supports owner-authorized storage audits, file recovery and organization, and backups from the Alpha server to Google Drive.

Alpha backups

The backup connection requests access to files created or explicitly opened with this app (the Google Drive drive.file permission). It verifies the connected account and available storage. Authorization alone does not start a backup.

Backup setup is in progress. Uploads and scheduling will be enabled only after storage checks and backup verification. Repository content already recoverable from GitHub and previously uploaded media are intended to be excluded after verification.

Personal use

This is a private utility for its owner, not a public backup service. These information pages are public; backup data and authorization credentials are not.
