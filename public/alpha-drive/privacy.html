Privacy policy

Effective October 15, 2026. This policy describes Jensen Abler’s personal Alpha Drive Tools, including the Alpha backup connection.

Data accessed and purpose

The backup connection accesses the authorized Google account’s email address, storage quota, and files created or explicitly opened with this app. It uses this information to verify the destination, check capacity, and upload, inspect, and retrieve backups. Earlier storage-audit and file-management tools may use separately granted Drive permissions to inspect metadata or perform actions requested by the owner.

Storage and protection

OAuth access and refresh tokens are stored on Alpha in files restricted to the service administrator. Tokens allow unattended access until expired or revoked. Backup contents are stored in the owner’s Google Drive. Google API requests use HTTPS. This policy does not promise additional client-side encryption of backup contents.

Sharing and use

Google processes authorization and stores uploaded files. The operator uses Google user data only to provide these requested functions. Google user data is not sold, used for advertising, or used to train generalized AI or machine-learning models. Access is not intentionally shared with other people unless the owner directs it or disclosure is required by law.

Retention and control

Backup versions may be retained until the owner deletes them; local deletions are not intended to automatically delete backups. Revoking authorization stops future API access but does not delete existing Drive files. The owner can delete backup files in Drive and request removal of credentials and local operational records.

You can revoke access through Google Account connections.

Google API policy

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.
